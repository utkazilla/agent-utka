# Harry Potter: a knowledge base demo

## Hedwig's birthday story

Rubeus Hagrid gave Harry Potter a snowy owl named Hedwig for Harry's eleventh birthday. Hagrid bought the owl at Eeylops Owl Emporium in Diagon Alley.
