# Как пользоваться Agent Utka

Agent Utka — ИИ-помощник для звонков в Windows.

1. Скачай установщик `.exe` со страницы [Releases](https://github.com/utkazilla/agent-utka/releases/latest) и запусти его на Windows 10 или 11 x64. Python уже внутри. Открой **Agent Utka** из меню «Пуск» и нажми **Download and start**, чтобы скачать модели. Первая загрузка займёт около 6 ГБ; оставь около 12 ГБ свободного места для скачивания и распаковки. [Установка из исходников](tutorial.md#run-from-source)
2. Выбери **Русский**, **English** или **Español** в меню с флагом. Запусти видео или звонок на устройстве вывода Windows по умолчанию. Если текст не появляется, проверь, что помощник слушает, а звук браузера или звонка идёт на то же устройство.
3. Нажми **«Папка…»** и выбери корень проекта или отдельную папку для базы. Для отдельной базы нажми **«Импорт…»** и выбери один или несколько документов `.md` или `.txt` в UTF‑8, до 180 000 байт каждый. Дождись статуса **«Готова»**. Можно начать с [вымышленного проекта Orbit](examples/orbit-knowledge.md).
4. Выдели услышанную реплику и нажми **«Дай ответ»** или **Ctrl+Enter**. Без выделения помощник берёт последнюю реплику. **«Источники»** открывает цитату и номер строки. **«История»** возвращает к предыдущим ответам.
5. Для своего проекта нажми **«Настройки» → «Копировать промпт»** и вставь его в чат Codex или Claude Code, открытый в рабочей папке. Проверь `utka-cue-knowledge.md`, который подготовит агент. Помощник подхватит его из корня подключённого проекта или из импорта. Чтобы обновить отдельную базу, импортируй новую версию файла под тем же именем. [Русский промпт](knowledge-pack-prompt.ru.md)

Ранее созданные файлы `utka-knowledge.md` и `call-copilot-knowledge.md`, а также блоки `utka-asr` и `call-copilot-asr` поддерживаются. Agent Utka индексирует текст всех доступных файлов знаний в корне проекта. Если доступен файл `utka-cue-knowledge.md`, приложение берёт словарь из него.

В **«Настройках»** независимо выбираются распознавание речи, модель ответов и поиск. Распознавание поддерживает Qwen3-ASR, Faster Whisper и локальный сервер, совместимый с OpenAI. Для ответов можно использовать встроенный Ollama, уже запущенный Ollama или другой локальный сервер с поддержкой JSON Schema. Поиск работает через SQLite или подключённый локальный API. Сохрани настройки и перезапусти приложение. [Требования к серверам и примеры](tutorial.md#choose-speech-answer-and-search-modules)

Чтобы сменить модель распознавания, открой **«Настройки» → «Распознавание речи» → «Выбрать модель…»**. Если выбран внешний сервер, сначала переключи источник на **«Встроенные модели»**. Сравни размеры файлов Qwen3-ASR 0.6B и многоязычных вариантов Faster Whisper от `tiny` до `large-v3`. Нажми **«Скачать и выбрать»** или **«Выбрать»** для установленной модели. Agent Utka скачает модель, при необходимости установит Faster Whisper и сохранит выбор. Если отменить загрузку, останется прежний выбор. Перезапусти приложение, чтобы модель начала расшифровывать речь. Для отдельного локального STT-сервера модели устанавливаются на самом сервере. [Подробности о распознавании](tutorial.md#speech-recognition)

Чтобы скачать модель Ollama, открой **«Настройки» → «Ответы» → «Выбрать модель…» → «Каталог»**. Найди семейство модели, выбери вариант по размеру файлов и нажми **«Скачать и выбрать»**. Agent Utka покажет прогресс и сохранит модель вместе с сервером ответов, когда Ollama закончит установку. Для уже скачанной модели открой **«Установленные»** и нажми **«Выбрать»**. Перезапусти приложение, чтобы оно начало использовать выбранную модель. Если ты также менял адрес внешнего сервера речи или параметры поиска, сохрани их в настройках перед перезапуском.

Число в обозначении `4b` означает четыре миллиарда параметров, а размер в ГБ показывает объём файлов модели. Кнопка **«Проверить VRAM»** показывает свободную и общую видеопамять NVIDIA, если данные доступны, и память уже загруженных в выбранный Ollama моделей. Реальное использование GPU зависит от модели, контекста и других процессов. [Как Ollama сообщает VRAM](https://docs.ollama.com/api/ps)

Данные для ответов лежат в локальном индексе. Полная расшифровка хранится в памяти окна, а последние ответы и их цитаты остаются в локальной истории. [Проверка установки и решение проблем](tutorial.md#local-data-and-common-fixes)
