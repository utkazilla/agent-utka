# Как пользоваться Agent Utka

Agent Utka — ИИ-помощник для звонков в Windows.

Кнопка **«Новая база»** всегда доступна на главном экране рядом со списком баз. Введи название и нажми **«Создать базу»** — файл или папка не нужны. Пустая база сразу выбирается и сохраняется после перезапуска. Дальше нажми **«Скопировать промпт»** или **«Импортировать»**. **«Открыть базу»** показывает документы и результаты поиска. Эти действия доступны в любой момент, а не только при первом запуске.

1. Скачай установщик `.exe` со страницы [Releases](https://github.com/utkazilla/agent-utka/releases/latest) и запусти его на Windows 10 или 11 x64. Python уже внутри. Открой **Agent Utka** из меню «Пуск» и нажми **Download and start**, чтобы скачать модели. Первая загрузка займёт около 6 ГБ; оставь около 12 ГБ свободного места для скачивания и распаковки. [Установка из исходников](tutorial.md#run-from-source)
2. Выбери **Русский**, **English** или **Español** в меню с флагом. Запусти видео или звонок на устройстве вывода Windows по умолчанию. Если текст не появляется, проверь, что помощник слушает, а звук браузера или звонка идёт на то же устройство.
3. Нажми **«Импорт файла…»** и выбери документ `.md` или `.txt` в UTF‑8. При первом импорте имя базы уже предложено по заголовку файла. Его можно изменить. Если базы уже есть, выбери нужную или пункт **«Новая база…»**. Нажми **«Импортировать»** и дождись **«Готово»**. Можно начать с [вымышленного проекта Orbit](examples/orbit-knowledge.md).
4. Выдели услышанную реплику и нажми **«Дай ответ»** или **Ctrl+Enter**. Без выделения помощник берёт последнюю реплику. **«Источники»** открывает цитату и номер строки. **«История»** возвращает к предыдущим ответам.
5. Для своего проекта нажми **«Скопировать промпт»** на главном экране и вставь его в чат Codex или Claude Code с этим проектом. Проверь `utka-cue-knowledge.md`, который подготовит агент, и импортируй его в нужную базу. В одну базу можно добавлять несколько выжимок. Для обновления выбери новую версию из того же места и ту же базу. [Русский промпт](knowledge-pack-prompt.ru.md)

В списке на главном экране выбери конкретную базу или **«Все базы»**. Этот выбор действует и на ответы, и на **«Открыть базу»**. При общем поиске рядом с найденными фрагментами и цитатами указаны названия баз. Папками хранения управляет приложение.

Промпт добавляет в выжимку раздел **Utka glossary** с краткими объяснениями терминов и источниками. Для простого вопроса вроде «Что такое LDT?» Utka берёт определение из выбранной базы. Если в двух базах значения различаются, показывает их отдельно. Если определения сокращения нет, Utka сообщает об этом. Чтобы пополнить словарь, обнови выжимку проекта целиком и импортируй тот же файл.

Кнопка **«Изменить название выжимки…»** открывает поле с именем документа в источниках. Чтобы переименовать уже добавленную выжимку, импортируй тот же файл в ту же базу и измени название. Utka обновит документ без дубля. Пункт **«Все базы»** в главном окне включает поиск по всем базам.

Чтобы спросить без речи, напиши или вставь текст в **«Свой вопрос»** на главном экране. Нажми **«Спросить»** рядом с полем или **Ctrl+Enter** внутри него. Enter добавляет новую строку. Вопрос использует выбранную базу или **«Все базы»**; ответ сохраняется в истории и показывает источники. Черновик остаётся в поле для уточнения, а новая речь его не меняет.

Agent Utka открывает раздел вокруг найденного фрагмента и может повторить поиск по более точным словам, если не удалось подтвердить полный ответ. В **«Источниках»** можно проверить использованные фрагменты. Поиск читает импортированные файлы; ссылка внутри выжимки сама по себе не даёт доступа к внешнему документу.

В **Настройки → Ответы** можно выбрать **OpenAI API · облако**, выбрать `gpt-4o` или ввести ID другой модели и добавить свой ключ. Ключ шифруется средствами Windows. Поиск остаётся на компьютере. При запросе ответа OpenAI получает текст вопроса и фрагменты из выбранной базы.

Рядом с заголовком расшифровки можно выбрать **Только по запросу** или **Автоматически**. В автоматическом режиме Utka ищет ответ, когда распознаёт вопрос в речи. При выбранном OpenAI такой вопрос и найденные фрагменты отправляются в API. Кнопки ручного запроса работают в обоих режимах.

**Настройки → База знаний → SQLite + поиск по смыслу** помогает искать по другим формулировкам. Режим использует `qwen3-embedding:0.6b`, если модель уже установлена на сервере Ollama для ответов. Пока индекс для поиска по смыслу недоступен, приложение ищет по словам в SQLite.

Промпт собирает всю доступную проектную историю чата, структуру кода, изменения MR/PR, обсуждения review и связанную документацию. Он требует реестр источников, карту покрытия, отдельные текущие и исторические сведения и явный список пробелов. Объём итогового документа и число записей полного словаря не ограничиваются.

Agent Utka строит локальный индекс и словарь терминов по импортированным документам. Ранее созданные файлы `utka-knowledge.md` и `call-copilot-knowledge.md` со словарями `utka-asr` и `call-copilot-asr` тоже можно импортировать.

В **«Настройках»** независимо выбираются распознавание речи, модель ответов и поиск. Распознавание поддерживает Qwen3-ASR, Faster Whisper и локальный сервер, совместимый с OpenAI. Для ответов можно использовать встроенный Ollama, уже запущенный Ollama или другой локальный сервер с поддержкой JSON Schema. Поиск работает через SQLite или подключённый локальный API. Кнопка **«Сохранить»** применяет изменения в текущем сеансе и закрывает окно. [Требования к серверам и примеры](tutorial.md#choose-speech-answer-and-search-modules)

Чтобы сменить модель распознавания, открой **«Настройки» → «Распознавание речи» → «Выбрать модель…»**. Если выбран внешний сервер, сначала переключи источник на **«Встроенные модели»**. Сравни размеры Qwen3-ASR и вариантов Faster Whisper. Нажми **«Скачать и выбрать»** или **«Выбрать»** для установленной модели. Agent Utka установит нужные зависимости и переключит модель в текущем сеансе. Если отменить загрузку, останется прежний выбор. Для отдельного локального STT-сервера модели устанавливаются на самом сервере. [Подробности о распознавании](tutorial.md#speech-recognition)

Чтобы скачать модель Ollama, открой **«Настройки» → «Ответы» → «Выбрать модель…» → «Каталог»**. Найди семейство модели, выбери вариант по размеру файлов и нажми **«Скачать и выбрать»**. Agent Utka покажет прогресс и применит модель вместе с сервером ответов, когда Ollama закончит установку. Для уже скачанной модели открой **«Установленные»** и нажми **«Выбрать»**.

Число в обозначении `4b` означает четыре миллиарда параметров, а размер в ГБ показывает объём файлов модели. Кнопка **«Проверить VRAM»** показывает свободную и общую видеопамять NVIDIA, если данные доступны, и память уже загруженных в выбранный Ollama моделей. Реальное использование GPU зависит от модели, контекста и других процессов. [Как Ollama сообщает VRAM](https://docs.ollama.com/api/ps)

Данные для ответов лежат в локальном индексе. Полная расшифровка хранится в памяти окна, а последние ответы и их цитаты остаются в локальной истории. [Проверка установки и решение проблем](tutorial.md#local-data-and-common-fixes)

Для Faster Whisper выбери **NVIDIA GPU (CUDA)** в окне моделей. Agent Utka скачает около 1,3 ГБ библиотек cuBLAS и cuDNN и проверит, что модель работает на GPU. Кнопка **«Выгрузить модель»** в разделе распознавания ставит прослушивание на паузу и освобождает модель. Кнопка **«Слушать»** возобновляет захват звука. Модели Ollama можно выгружать из настроек ответов и из каталога.

В **«Открыть базу»** на главном экране видны проиндексированные документы, их фрагменты и номера строк. Введи вопрос и нажми **«Проверить поиск»**, чтобы увидеть, какие фрагменты приложение передаст модели для ответа.
